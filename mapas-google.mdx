## Ative os mapas do Google no cardápio digital com uma chave de API

O BeeFood usa o Google Maps para mapa, rotas e geolocalização. Para isso, você precisa criar uma chave de API ligada à sua conta Google e depois colar essa chave no BeeFood em **Aplicativos → Mapas Google**.

Depois de salvar a chave, o sistema consegue usar recursos como busca de endereço, cálculo de distância e exibição do mapa no cardápio digital. Se você também precisa desenhar a área de entrega, use o manual de [Área de entrega](/area-entrega).

<Callout kind="info" collapsed="false">

Você vai fazer duas partes neste processo:

- **Google Cloud**: criar ou localizar a chave e ativar as APIs necessárias
- **BeeFood**: colar a chave no cardápio e salvar

</Callout>

## Vou pagar pela chave de API da Google?

A criação da conta e da chave de API pode começar sem custo de uso imediato, mas o Google exige uma conta de faturamento com cartão cadastrado. Esse cartão funciona como validação da conta e também cobre uso acima dos créditos disponíveis.

<Callout kind="tip" collapsed="false">

**Crédito inicial de teste**: o Google oferece **US$ 300** em créditos válidos por **90 dias**. Esse crédito é oferecido uma vez, não renova todo mês, e termina quando você usa todo o valor ou quando os 90 dias acabam.

</Callout>

<Callout kind="info" collapsed="false">

**Crédito mensal depois do teste**: após o período inicial, o Google oferece **US$ 200 por mês** para APIs de mapas. Em muitos casos, esse valor cobre o uso normal do cardápio digital sem cobrança adicional.

</Callout>

<Callout kind="alert" collapsed="false">

Mesmo em conta de teste, o Google pode pedir **cartão de crédito internacional** para ativar o faturamento. Se o uso passar do crédito disponível, a cobrança acontece na conta Google, não no BeeFood.

</Callout>

Se a validação passar, a chave já libera geolocalização no cardápio e no sistema. Isso inclui busca de endereço, distância e mapa.

</Step>

## Problemas comuns

| Problema | O que verificar |
|----------|------------------|
| Mapa não carrega no cardápio | Confira se a chave foi salva no cardápio certo e se as 4 APIs necessárias estão ativas no Google Cloud |
| Validação reprova uma API | Ative a API que faltou, como **Places API (New)**, **Places API**, **Routes API** ou **Distance Matrix API**, e salve novamente |
| Cobrança inesperada | Verifique o uso no faturamento do Google. O crédito mensal de US$ 200 tem limite, e uso acima desse valor pode gerar cobrança |
| A chave não funciona depois de colar | Confirme se a chave foi copiada inteira e se começa no formato esperado, como `AIzaSy...` |

## Perguntas frequentes

<ExpandableGroup>
<Expandable title="A chave do Google Maps serve para quê?" default-open="false">

Ela habilita os recursos de geolocalização no BeeFood e no cardápio digital. Isso inclui busca de endereço, cálculo de distância, rotas e exibição do mapa.

</Expandable>

<Expandable title="Preciso desenhar a área de entrega nesta mesma tela?" default-open="false">

Não. A configuração da chave libera o uso do Google Maps, mas o desenho da área de entrega é outro processo. Para isso, use o manual de [Área de entrega](/area-entrega).

</Expandable>

<Expandable title="Preciso pagar para criar a chave?" default-open="false">

Você pode criar a conta e a chave com os créditos oferecidos pelo Google, mas precisa cadastrar uma forma de pagamento para ativar o faturamento da conta.

</Expandable>

<Expandable title="Posso usar uma chave já existente?" default-open="false">

Sim. Se sua conta Google Cloud já tem uma chave cadastrada e as APIs necessárias estão ativas, você pode copiar essa mesma chave e colar no BeeFood.

</Expandable>
</ExpandableGroup>

## Precisa de ajuda?

Fale com o suporte BeeFood informando o **nome da loja**, o **CNPJ** e um print do modal de configuração. Não compartilhe a chave completa em canais públicos.
