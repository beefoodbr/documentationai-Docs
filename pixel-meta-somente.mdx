## Conecte o Pixel da Meta ao cardápio digital usando só o Pixel ID

Este é o caminho antigo: você cria o Pixel na Meta e cola só o **Pixel ID** no BeeFood, sem token da API de Conversões. O método recomendado hoje é **Pixel da Meta + API de Conversões**, porque envia mais dados mesmo quando o celular do cliente bloqueia parte do rastreamento.

Alguns dados podem não ser capturados em celulares com a privacidade ativa. Por isso, a API de Conversões costuma registrar os eventos com mais precisão.

### Eventos rastreados depois de salvar

- **Visualizar conteúdo**
- **Adicionar ao Carrinho**
- **Inicialização de Compra**
- **Compra**

## Antes de começar

<Callout kind="info" collapsed="false">

Você precisa ter estes itens em mãos antes de configurar:

- Conta **Business** da Meta com acesso ao **Gerenciador de Eventos**
- Conta BeeFood com pelo menos um **cardápio digital**
- **URL do seu cardápio digital**, porque a Meta usa esse endereço para verificar o site

</Callout>

<Callout kind="alert" collapsed="false">

Use este caminho só quando você tiver **apenas o Pixel ID**. Se você já tiver **Identificador e Token**, prefira o manual **Pixel da Meta + API de Conversões**.

</Callout>

|---|---|---|
| 1 | **Pixel ID Delivery** | Cole o número copiado na Meta |

## Problemas comuns

| Sintoma | O que verificar |
|---|---|
| Eventos falhos no celular | A privacidade do aparelho pode bloquear parte do Pixel. Quando possível, prefira **Pixel da Meta + API de Conversões** |
| Não sei qual caminho usar | Se você tem **Identificador** e **Token**, use o caminho recomendado com **API de Conversões** |
| Configurei e não vi mudança | Confirme se você colou o número no cardápio correto e clicou em **SALVAR (F2)** |
| Preenchi campos presenciais sem querer | Limpe os campos de presencial e mantenha só o **Pixel ID Delivery** para este manual |

## Perguntas frequentes

<ExpandableGroup>
<Expandable title="Quais eventos o BeeFood envia depois da configuração?" default-open="false">

O cardápio digital passa a enviar estes eventos:

- **Visualizar conteúdo**
- **Adicionar ao Carrinho**
- **Inicialização de Compra**
- **Compra**

</Expandable>

<Expandable title="Posso preencher o token também?" default-open="false">

Não neste caminho. Se você tiver token, use o método recomendado **Pixel da Meta + API de Conversões**. Nesta página, o preenchimento correto é só o **Pixel ID Delivery**.

</Expandable>

<Expandable title="Preciso preencher campos de presencial?" default-open="false">

Não. Neste manual, deixe **Token Delivery** em branco e não preencha **Pixel ID Presencial** nem **Token Presencial**.

</Expandable>

<Expandable title="Por que alguns eventos podem falhar no celular?" default-open="false">

Alguns celulares bloqueiam parte do rastreamento quando as opções de privacidade estão ativas. Por isso o caminho com API de Conversões costuma capturar mais dados.

</Expandable>
</ExpandableGroup>

## Precisa de ajuda?

Fale com o suporte BeeFood informando o **nome da loja**, o **CNPJ** e qual **cardápio digital** você está configurando. Se possível, envie também um print do modal para mostrar em qual etapa parou.
