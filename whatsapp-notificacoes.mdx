## 🔔 Notificações do WhatsApp

Cada vez que um pedido muda de situação no Delivery, o BeeBot pode enviar uma mensagem de WhatsApp para o cliente. Ative, desative e edite o texto dos avisos em **WhatsApp → Notificações**.

## Onde encontrar

Abra **WhatsApp → Notificações**.

<Image src="https://raw.githubusercontent.com/BeeFood-Sistema-para-Restaurantes/beefood-web-react-manual/main/manuais/whatsapp-notificacoes/imagens-tratadas/01-lista.png" width="800" height="450" alt="Lista de notificações do WhatsApp" />

| Nº | Item | O que faz |
|---|---|---|
| 1. | Grupo **Delivery** | Reúne as mensagens relacionadas às etapas do pedido. |
| 2. | **Interruptor** | Liga ou desliga o aviso daquela etapa. |
| 3. | **Lápis** | Abre a mensagem para edição. |

O grupo **Entregador** reúne avisos destinados ao motoboy, como nova entrega, cancelamento e relatório diário. O cliente não recebe essas três notificações.

## Os avisos do Delivery

Os oito avisos do grupo **Delivery** começam ligados. Desligue os tipos que a loja não utiliza.

| Tipo | Quando dispara |
|---|---|
| **Pedido feito** | O pedido entrou no Delivery. |
| **Pedido confirmado** | A loja confirmou o pedido ou começou o preparo. |
| **Pedido pronto para retirada** | O pedido está pronto para retirada no balcão. |
| **Pedido saiu para entrega** | O pedido saiu com o entregador. |
| **Pedido retirado ou entregue** | O pedido foi retirado ou entregue ao cliente. |
| **Pedido cancelado** | O pedido foi cancelado. |
| **Pedido pronto para consumo no local** | O pedido está pronto para consumo no salão. |
| **Entregador próximo** | O entregador está dentro do raio definido em relação ao cliente. |

## Como editar o texto

Edite uma mensagem quando precisar ajustar o tom da loja, incluir informações próprias ou usar variações para evitar o envio repetido do mesmo texto.

<Steps>
  <Step title="Editar a mensagem de Pedido feito" title-type="p">

Clique no lápis de **Pedido feito**, altere o conteúdo e salve a mensagem.

<Image src="https://raw.githubusercontent.com/BeeFood-Sistema-para-Restaurantes/beefood-web-react-manual/main/manuais/whatsapp-notificacoes/imagens-tratadas/02-editar-pedido-feito.png" width="800" height="450" alt="Tela de edição da notificação Pedido feito" />

| Nº | Item | O que faz |
|---|---|---|
| 1. | **Mensagem principal** | Define o texto padrão enviado ao cliente. |
| 2. | **Variações** | Permite cadastrar até três textos extras. O sistema escolhe uma mensagem a cada envio. |
| 3. | **SALVAR (F2)** | Grava as alterações feitas na mensagem. |
| 4. | **Restaurar padrão** | Recupera o texto original da fábrica. |

Use **CANCELAR (ESC)** para sair sem gravar as alterações.

  </Step>
</Steps>

## Variáveis disponíveis

Insira as variáveis no texto para preencher automaticamente os dados do cliente, do pedido e da loja.

| Variável | Informação inserida |
|---|---|
| `**CLIENTE_NOME**` | Nome do cliente. |
| `**VENDA_NUMERO**` | Número do pedido. |
| `**VENDA_PRODUTOS**` | Produtos do pedido. |
| `**VENDA_TOTAIS**` | Totais do pedido. |
| `**VENDA_ENTREGA**` | Informações da entrega. |
| `**VENDA_PAGAMENTO**` | Forma de pagamento. |
| `**MEU_NOME_FANTASIA**` | Nome fantasia da loja. |
| `**MEU_MINUTOS_DELIVERY**` | Tempo estimado do Delivery em minutos. |
| `**MEU_LINK_CONSULTA**` | Link para consultar o pedido. |
| `**VENDA_LINK_AVALIACAO**` | Link para avaliar o pedido. |

Para alternar palavras automaticamente, use chaves com barra. O formato ``{Olá|Oi}`` faz o sistema escolher uma das opções a cada envio.

Você também pode cadastrar até três variações completas da mensagem. Alterar o texto e usar variações reduz a repetição de frases nas conversas.

## Entregador próximo (raio)

A notificação **Entregador próximo** tem um campo adicional para definir a distância em que o aviso será enviado.

<Image src="https://raw.githubusercontent.com/BeeFood-Sistema-para-Restaurantes/beefood-web-react-manual/main/manuais/whatsapp-notificacoes/imagens-tratadas/03-editar-entregador.png" width="800" height="450" alt="Tela de edição da notificação Entregador próximo" />

| Nº | Item | O que faz |
|---|---|---|
| 1. | **km do cliente** | Define a distância entre o entregador e o cliente para disparar o aviso. |
| 2. | **Mensagem** | Texto enviado quando o entregador entra no raio configurado. |

O valor padrão é **2 km**. Informe uma distância entre **0,1 e 50 km**. Quanto maior o valor, mais cedo o cliente recebe o aviso.

A mensagem pode usar as variáveis `**ENTREGADOR_NOME**` e `**VENDA_ENTREGA**`. Para não enviar esse aviso, desligue o interruptor na lista de notificações.

## O que o cliente vê

Com o WhatsApp conectado, a notificação chega ao cliente como uma conversa normal da loja.

<Image src="https://raw.githubusercontent.com/BeeFood-Sistema-para-Restaurantes/beefood-web-react-manual/main/manuais/whatsapp-notificacoes/imagens-tratadas/04-whatsapp-notificacao.png" width="800" height="450" alt="Notificação de pedido recebida pelo cliente no WhatsApp" />

| Nº | Item | O que mostra |
|---|---|---|
| 1. | **Mensagem da loja** | O aviso correspondente à etapa alcançada pelo pedido. |

<Callout kind="alert">

Deixe o interruptor **Notificação Campanhas** ligado no BeeBot. Se essa opção estiver desligada, as notificações do pedido não serão disparadas.

</Callout>

## Perguntas frequentes

<ExpandableGroup>
  <Expandable title="Editei e o cliente não recebeu" default-open="false">

Confirme se o número do WhatsApp está conectado, se o interruptor da notificação está ligado e se o pedido realmente passou pela situação correspondente no Delivery.

  </Expandable>

  <Expandable title="Posso mandar a mesma frase em todas as etapas?" default-open="false">

Pode, mas o WhatsApp pode tratar textos repetidos como risco. Use variações com ``{a|b}`` e cadastre as quatro opções de texto disponíveis na tela para variar as mensagens.

  </Expandable>

  <Expandable title="O boletim das 07h entra aqui?" default-open="false">

Não. O boletim de faturamento da loja pertence ao **Resumo Diário**, não às notificações de cada etapa do pedido.

  </Expandable>
</ExpandableGroup>

## Precisa de ajuda?

Se a mensagem não for enviada, verifique primeiro a conexão do WhatsApp, o interruptor **Notificação Campanhas** e o status do pedido no Delivery. Em seguida, consulte o **Histórico** para confirmar o resultado do envio.
